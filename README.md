# BB84 Quantum Cryptography Simulation

A Python-based simulation of the BB84 quantum key distribution protocol, including an eavesdropping scenario.

## Overview

This academic project simulates the exchange of quantum bits between Alice and Bob and examines how an eavesdropping attempt by Eve affects the resulting key.

## Features

- Simulation of Alice and Bob key generation
- Random basis selection
- Eavesdropping simulation using Eve
- Key sifting based on matching bases
- QBER (Quantum Bit Error Rate) calculation
- Execution time measurement

## Technologies

- Python
- Quantum cryptography concepts
- Randomized simulation

## Project purpose

The project was developed as part of a university course in Cryptography and Information Security to explore the principles behind the BB84 quantum key distribution protocol and the detection of eavesdropping through error rates.
